# momo.ai

Plant care app — built **part by part**.

## Part 1 — Opening

Cinematic app launch: atmosphere → **momo.ai** brand → Open app.

```bash
npm install
npm start
```

Open **http://localhost:8787** (server binds `0.0.0.0` for cloud preview).
